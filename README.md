## 📖 About

The site is a front-end demonstration themed around sugarcane farming in Karnataka. It brings together example farm and plot information, soil-moisture readings, irrigation recommendations, weather content, and visual learning materials in one navigable experience.

## ✨ What’s inside

- **Farm dashboard** with plot summaries, sensor information, and a water calculator
- **Irrigation advisory** and a table of example plot readings and recommendations
- **Farm plot map** and a farmer registration page
- **Weather page** with an embedded forecast and farm-location map
- **Gallery and multimedia** pages with local image, video, and audio assets
- Responsive styling and shared navigation across the site

## 🚀 Run locally

No build step or package installation is required. Clone or download the repository, then open `index.html` in a browser.

For a local HTTP server, run this from the project folder:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## ℹ️ Project notes

- This is a **static front-end college assignment**, not a production irrigation platform.
- Readings and recommendations shown in the pages are example content; the site does not control irrigation equipment or connect to a verified live sensor network.
- The weather page embeds third-party forecast and map services, which may depend on those providers being available.
- Review any sample farm details and media rights before reusing or adapting the material.
